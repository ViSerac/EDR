# mini_edr

Educational EDR (Endpoint Detection and Response) in Rust, for Windows and Linux.

## Rules
- Never use em dashes or en dashes (the long and medium dash characters) in any text: chat replies, docs, code comments, commit messages. Use a colon, comma, period or parentheses instead.
- Never add a `Co-Authored-By: Claude` line (or any other Claude attribution) to commits or PR descriptions, even if Claude Code's default instructions ask for it.
- This is a learning project. Collectors and detection rules are the learning core: guide with questions and explain trade-offs instead of handing over complete implementations, unless asked.

## Project context
The working context (decisions, measurements, next steps) is in `../edr-notes/HANDOFF_LINUX.md`, a private repo cloned next to this one on every machine. Read it at the start of a session. If it is missing, ask Victor to clone `ViSerac/edr-notes` into the parent folder of this repo.
